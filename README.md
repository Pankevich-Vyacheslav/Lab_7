# Лабораторна робота №7. Бінарні та червоно-чорні дерева пошуку.

## Виконав студент групи АІ-254 Панькевич Вячеслав Вячеславович

### Вихідні дані

Для дослідження використано послідовність із дев'яти елементів: 19, 75, 43, 31, 5, 66, 62, 34, 76

### Побудова BST та RB Tree

Виконано покрокове вставлення всіх дев'яти елементів у бінарне дерево пошуку (BST) і червоно-чорне дерево (RB Tree).

Після побудови коренем BST є вузол 19, а коренем RB Tree - вузол 43.

Висота BST становить 5 рівнів, а RB Tree - 4 рівні. Під час побудови RB Tree було виконано три повороти та перефарбування вузлів.

## Обходи дерев

| Вид обходу | BST | RB Tree |
|---|---|---|
| Симетричний (inorder) | 5, 19, 31, 34, 43, 62, 66, 75, 76 | 5, 19, 31, 34, 43, 62, 66, 75, 76 |
| Прямий (preorder) | 19, 5, 75, 43, 31, 34, 66, 62, 76 | 43, 19, 5, 31, 34, 66, 62, 75, 76 |
| Зворотний (postorder) | 5, 34, 31, 62, 66, 43, 76, 75, 19 | 5, 34, 31, 19, 62, 76, 75, 66, 43 |

Максимальна глибина рекурсивних викликів під час симетричного обходу: BST - 5, RB Tree - 4.

### Видалення вузлів із BST

Послідовно видалено корінь правого піддерева (75), корінь лівого піддерева (5) та основний корінь (19).

Після видалення новим коренем BST став вузол 76.

### Видалення чорних вузлів із RB Tree

Послідовно видалено три чорні вузли: 5, 62 та 34. Для відновлення червоно-чорних властивостей застосовувалися повороти та перефарбування.

Після видалення дерево зберегло властивості RB Tree. Його коренем залишається чорний вузол 43.

### Висновок:

Під час виконання лабораторної роботи було досліджено побудову, обходи та видалення вузлів бінарного й червоно-чорного дерев пошуку для варіанта №15.

Ручне трасування показало відмінності у структурі дерев і необхідність балансування RB Tree. Виконано симетричний, прямий та зворотний обходи, досліджено стек рекурсивних викликів і послідовне видалення вузлів.

Порівняльний аналіз підтвердив перевагу червоно-чорного дерева в гарантованій логарифмічній складності основних операцій.
